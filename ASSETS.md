# Asset sources

Every visual asset on the site, where it came from, and its licence.
Licensed GLB/glTF models and photography could not be downloaded from the
build environment (only npm and GitHub raw files were reachable), so the
3D models are procedural for now. Each is one component and can be swapped
for a licensed model without touching the scenes.

## 3D models (procedural, written for this project)

| Object | Component | Swap point |
| --- | --- | --- |
| Passenger aircraft | `src/components/three/Aircraft.tsx` | replace `Aircraft` with a `useGLTF` model, nose along +x |
| Passport, boarding pass, suitcase, documents, parcel, compass, stamp | `src/components/three/TravelObjects.tsx` | one exported component each |
| Camera, document folder, desk calendar, pen, postcards, checklist sheets | `src/components/three/ObjectsExtra.tsx` | one exported component each |
| Open book with page turns | `src/components/three/scenes/BookScene.tsx` | page textures are canvas-drawn |
| Landmark silhouettes | `src/components/three/scenes/silhouettes.ts` | stylised outlines, not architectural models |

## Geography

| Asset | Source | Licence |
| --- | --- | --- |
| `public/globe/earth.jpg`, `earth-rough.jpg` | Natural Earth 1:50m land, via the `world-atlas` npm package, rendered by `scripts/generate-geo-art.py` | Public domain |
| `public/geo/sri-lanka.json`, `public/images/scenes/lanka-*.{png,webp}` | Natural Earth 1:10m countries (Sri Lanka), same pipeline. Relief is stylised around the central highlands. | Public domain |
| `public/globe/land-points.json`, `public/images/globe/static.png` | Generated by `scripts/generate-land-points.py` and `scripts/generate-static-globe.py` | Project-generated |

## Images

| Asset | Source |
| --- | --- |
| `public/images/destinations/*.jpg`, `articles/*.jpg`, `about/jaffna.jpg` | Generated illustrations (`scripts/art/`), labelled as such on the site. Replace with licensed photography when supplied. |
| `public/images/hero/poster.jpg` | Still rendered from the hero 3D scene |
| `public/images/scenes/poster-*.webp` | Stills captured from each homepage scene by `scripts/capture-scene-posters.cjs`; shown for reduced motion, no WebGL and while 3D loads |

No people are generated or used. The managing director's portrait will be
shown only when the genuine photo is supplied (`site.managingDirector.portrait`).
